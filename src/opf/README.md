# Optimal Power Flow and VQLS Experiments

This directory contains research prototypes that connect security-constrained primal-dual interior-point optimization (SC-PDIPM) with a Variational Quantum Linear Solver (VQLS). The core experiment constructs a Karush-Kuhn-Tucker (KKT) linear system for a small three-bus optimal-power-flow case, preprocesses it for quantum solution, and compares the recovered search direction with a classical reference.

## Files

| File or directory | Purpose |
|---|---|
| `scpdipm_kkt_case3sc_paper.py` | Constructs and preprocesses the paper-style 16-by-16 SC-PDIPM KKT system. |
| `vqls_scpdipm_case3sc_paper_complete.py` | Runs VQLS on the prepared KKT system and evaluates the recovered search direction. |
| `load_case3.py` | Alternate or duplicated preparation script for the same small case. |
| `vqls_test.py` | Smaller exploratory VQLS test. |
| `scpdipm_case3sc_paper_matrix.npz` | Saved matrix/vector data for the SC-PDIPM experiment. |
| `outputs_vqls_scpdipm_paper/` | Generated comparison figure(s). |
| `__pycache__/` | Automatically generated Python bytecode; not source code. |

## KKT preparation

`scpdipm_kkt_case3sc_paper.py` builds a 16-dimensional search-direction system with variables grouped as:

```text
[dX, dZ, dLambda, dMu]
```

The preparation pipeline is:

1. construct the full KKT matrix and right-hand side at an interior iterate;
2. apply left ILU preconditioning;
3. scale the matrix by its spectral norm;
4. normalize the right-hand side for amplitude encoding; and
5. expose the prepared arrays and metadata for the VQLS module.

Because the preconditioner is applied on the left, the unknown search direction is not transformed and does not require a symmetric-scaling recovery step.

## VQLS experiment

`vqls_scpdipm_case3sc_paper_complete.py` imports the prepared system, decomposes its matrix into Pauli terms, constructs a parameterized ansatz, performs classical optimization of the VQLS cost, rescales the statevector-derived result, and compares the search direction with the classical solution.

The default configuration uses multiple optimizer restarts and a relatively deep ansatz. A complete run may therefore take significant time.

## Run

Run from this directory so the preparation module can be imported by name:

```bash
cd src/opf
python scpdipm_kkt_case3sc_paper.py
python vqls_scpdipm_case3sc_paper_complete.py
```

Principal dependencies:

```text
numpy
scipy
matplotlib
qiskit
```

## Outputs

The `outputs_vqls_scpdipm_paper/` directory stores the plot generated by the complete VQLS experiment. The `.npz` file stores reusable numerical arrays for inspecting or reproducing the prepared system.

## Notes

- `load_case3.py` and `scpdipm_kkt_case3sc_paper.py` overlap substantially. Check the imports in the VQLS script before changing either file.
- This is a single-iterate, small-case research demonstration, not a complete production OPF engine.
- Pauli decomposition and variational optimization scale poorly as the KKT dimension grows.
- Reproduction requires recording the random seed, optimizer settings, ansatz depth, preprocessing parameters, and exact input matrix.
