# Generated FDLS Figures

This directory stores figures generated by the FDLS experiment located directly under `src/`.

## Current files

| File | Description |
|---|---|
| `fdls_loss_comparison.png` | Convergence-loss history for the classical, HHL, and VQLS FDLS runs. |
| `vm_solution_comparison.png` | Final bus voltage-magnitude comparison. |
| `va_solution_comparison.png` | Final bus voltage-angle comparison. |

These files are outputs, not source code. They can be regenerated by running:

```bash
cd src
python main.py
```

The output location is configured in `src/config.py` and the plotting logic is implemented in `src/plotting.py`.
